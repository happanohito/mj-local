# ローカル麻雀 Web アプリケーション 要件定義

## 1. 利用環境と対局形式

- PCのブラウザで動作する。アプリの起動後、対局の開始から結果表示まで、インターネット接続なしで利用できる。アプリに必要な画像やスクリプトもPC内から読み込む。
- 人間1人とCPU3人で、四人打ちリーチ麻雀の東風戦を行う。オンライン対戦機能は設けない。
- 東1局から開始し、東4局を最終局とする。東4局の連荘はあり、南入はなし。

## 2. 対局画面と操作

- 自分の手牌、各席の捨て牌・副露・持ち点、現在の局、親、本場、リーチ供託、公開済みのドラ表示牌を確認できる。
- プレイヤーは打牌、チー、ポン、大明槓、暗槓、加槓、リーチ、ツモ和了、ロン、見送り、九種九牌による途中流局の宣言ができる。チーなどで複数の組み合わせがある場合は選択できる。
- ツモは自動で進める。プレイヤーに操作の選択肢がある場面では、可能な操作を表示して入力を待つ。
- 新規対局、再開、打牌、副露や和了の選択、結果画面の進行、リセットなど、対局に必要な操作はすべてマウスで行える。打牌する牌や操作ボタンはクリックで選ぶ。
- 初版のプレイヤー操作は時間無制限とする。将来の拡張候補として、打牌の制限時間を設定できるようにし、時間切れ時はルール上打てる牌からランダムに1枚を自動で捨てる。制限時間の長さと、鳴き・和了など打牌以外の操作での時間切れの扱いは、その機能を追加するときに決める。

## 3. 和了判定とドラ

- 一般的な四人打ちリーチ麻雀に準拠する。喰いタン・後付けあり、喰い替えなしとする。和了形、役・役満、符・翻、フリテン、鳴きと和了宣言の優先順位を処理する。
- 表ドラ、槓ドラ、裏ドラ、槓裏、赤ドラを扱う。和了時に適用条件を満たしたドラをすべて数え、同じ牌が複数のドラに該当する場合は重複して加算する。裏ドラと槓裏はリーチして和了した場合に適用する。ドラは翻に加算し、和了には別途役が必要。
- 赤ドラは赤5萬・赤5筒・赤5索を各1枚、計3枚とする。
- 同じ打牌に2人がロンした場合は、両方の和了を認める。放銃者は両者へそれぞれの和了点を支払い、本場分とリーチ供託は放銃者からツモ順で先の和了者に支払う。親が和了者に含まれれば、親の和了として進行を判定する。
- 同じ打牌に3人がロンした場合は、途中流局として親が連荘する。ほかの途中流局は九種九牌、四風連打、四家立直、四槓散了を採用し、いずれも親が連荘する。

## 4. 局の進行と対局終了

| 局の結果 | 東1〜3局 | 東4局 |
| --- | --- | --- |
| 親がツモまたはロンで和了 | 親が連荘 | 点数精算後に親が首位なら自動終了。首位以外なら連荘 |
| 子だけが和了 | 親が交代し、次の局へ | 対局終了 |
| 通常流局で親がテンパイ | 親が連荘 | 流局の点数精算後に親が首位なら自動終了。首位以外なら連荘 |
| 通常流局で親がノーテン | 親が交代し、次の局へ | 対局終了 |
| 途中流局 | 親が連荘 | 親が連荘 |

- トビが発生したら対局を終了する。トビの条件は持ち点がマイナスになること。0点ではトビは成立しない。
- 持ち点が同じ場合は東1局の席順で東・南・西・北の順に上位とする。東4局のアガリやめ・テンパイやめの首位判定と、最終順位の両方に適用する。
- 対局終了時に残ったリーチ供託は最終首位に加算する。

## 5. 点数計算と結果表示

- 開始持ち点は各席25,000点とする。
- 和了点、本場、リーチ供託、通常流局のノーテン罰符を計算し、各席の持ち点に反映する。
- 1本場につき、ロンは放銃者が300点、ツモは支払う3席が各100点を加算する。ダブロンの本場分は第3節に従う。親の和了または流局のあとに対局が続く場合は本場を1つ増やし、子だけの和了のあとは0本場に戻す。
- 通常流局でテンパイ者とノーテン者が両方いる場合は、ノーテン者からテンパイ者へ合計3,000点を移す。全員テンパイまたは全員ノーテンの場合は移動しない。流し満貫が成立した場合はノーテン罰符に代えて満貫を精算し、連荘は親のテンパイで判定する。
- 各局終了時は局の結果と各席の点数増減を表示する。和了時は和了者、和了牌、役、ドラの内訳、符・翻または役満を表示する。通常流局時はテンパイ者と点数移動を表示し、流し満貫が成立した場合は成立者も表示する。途中流局時は成立した条件を表示する。
- 対局終了時は、残ったリーチ供託の配分後の最終順位と持ち点を全員分表示する。ウマ・オカの換算は省く。

## 6. 中断・再開とリセット

- 進行中の対局を1件、ブラウザのローカルストレージ領域に自動保存する。ブラウザを閉じたりページを読み直したりしても、同じブラウザから保存済みの対局を再開できる。
- 再開時は、局・手番、持ち点、手牌、山と王牌、捨て牌と副露、リーチ・フリテンの状態、処理待ちの操作などを復元する。未選択の操作を待っていた場合は、その選択から再開する。
- プレイヤーは「対局をリセット」から、進行中の対局とその保存データを手動で初期化できる。確認後に保存データを削除して開始画面へ戻り、新しい対局を開始できる。キャンセルした場合は対局を続けられる。

## 7. CPU

- 初版の難易度は1段階とする。CPU3席は共通の判断ロジックを使い、各席が参照できる自分の手牌と公開情報から操作を選ぶ。
- 将来、難易度ごとの判断ロジックを、対局の進行や点数計算を変更せずに追加できる構成とする。

## 8. ルールの参照先

局内の判定と点数計算は、天鳳公式マニュアルの四人打ち段位戦ルールを基準にする。役の一覧、符・翻、槓ドラをめくるタイミング、リーチや鳴きの成立条件などに適用する。この文書に規定がある項目は、ここに記載した内容を優先する。

- [天鳳公式マニュアル 四人打ちルール](https://tenhou.net/man/#RULE)
- [日本プロ麻雀協会公式ルール](https://npm2001.com/about/rule/)
- [Mリーグ公式戦ルール](https://m-league.jp/about/)
